# 일평균 환경 점수 + 실시간 대시보드 분리 — 설계 스펙

- 작성일: 2026-07-19
- 범위: **프론트엔드 목업 표시 방식만** (점수 산정 로직은 백엔드 카운슬 v2 결론에 따라 미정 상태 유지)
- 기반 브랜치: `feature/realtime-dashboard-split` (Shop 탭 커밋 위에 적층)

## 배경

- 현재 목업은 단일 시점 측정 기준 환경 점수(68점)를 표시한다.
- 백엔드 카운슬 v2(`backend/docs/debate/v2/04_synthesis.md`)는 복합 점수 산정을 근거 부족으로 봉인했다.
  이 스펙은 **표시 방식/화면 구조만** 다루며, 점수 값은 여전히 예시 데이터이다.
- 요구: ① 환경 점수를 "최근 24시간 평균" 기준으로 표시, ② 실시간 측정값 전용 화면을 분리.

## 결정 사항 (사용자 확정)

| 항목 | 결정 |
|---|---|
| 작업 범위 | 프론트 목업 표시 방식만 |
| 실시간 화면 | 새 화면(`RealtimeScreen`) 추가 |
| 기존 대시보드 역할 | 종합요약 + 이력/추이 (둘 다 유지) |
| 일평균 기준 창 | 최근 24시간 이동평균 |
| 대시보드 지표 카드 | 24시간 평균 카드로 교체 (값 = 24h 평균, 서브 = 최저·최고) |

## 화면 구조 (4탭)

앱바 탭: `환경 점수 | 대시보드 | 실시간 | 구매`
(`App.tsx`의 `Screen` 타입에 `'realtime'` 추가, 구매 탭은 기존 유지)

### 1. ScoreScreen — 최근 24시간 평균 기준

- 게이지 아래 메타: `'방울토마토' 기준 · 최근 24시간 평균 (07-13 10:30 ~ 07-14 10:30)`
- 세부 항목(FactorRow) 값 = 24시간 평균값, 표기 `24h 평균 24.1℃` 형식. 부족/초과 문구도 평균 기준.
- 하단 CTA: `실시간 측정값 보기 →` → RealtimeScreen 이동 (기존 onDashboard CTA 대체).
- 면책 문구 관례 유지 (점수 산정 로직 미정 명시).

### 2. DashboardScreen — 종합요약 + 추이

- 상단 요약바(작물 + 점수 필 + 온라인 상태) 유지. 점수 필도 24h 평균 의미.
- 지표 카드 4개 → 24시간 평균 카드: 값 = 24h 평균, 서브 = `24h 평균 · 최저 21.8 · 최고 26.3` 식.
- 시계열 차트 섹션 유지.
- 요약바에 `실시간 보기 →` 링크 추가.

### 3. RealtimeScreen — 신규 실시간 전용

- 상단: 온라인 상태 + `마지막 수신 방금 전` + 자동 갱신 안내.
- 기존 `latest` 실시간 카드 4개 이동 (현재값 + 최적범위 대비 서브텍스트).
- 목업 연출: 3초 간격 `setInterval`로 기준값 ± 소폭 랜덤 흔들림 (unmount 시 clear).
- 카드마다 최근 1시간 미니 스파크라인 (기존 SVG Polyline 패턴 재사용).

### 4. data.ts

- `score`: 24h 평균 의미 메타(`windowStart`/`windowEnd`) 추가.
- `factors`: `avg24h`, `min24h`, `max24h` 목업 값 추가.
- `latest`: 실시간 화면 전용. 대시보드용 `dailyAvg` 카드 데이터 신설.
