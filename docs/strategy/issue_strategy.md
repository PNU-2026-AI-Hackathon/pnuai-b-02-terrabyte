# Issue Strategy

Issue는 적극적으로 활용하는 것을 권장하며, 아래 규칙은 참고사항으로 삼아 자유롭게 활용합니다.

## Issue 작성 규칙
- 하나의 Issue에는 하나의 논리적 작업만 포함합니다.
- Issue는 자유롭게 작성하되, 작업 목적이나 필요한 내용을 알아볼 수 있게 작성합니다.

## 관리 규칙
- 작업을 시작하기 전에 Issue를 생성합니다.
- 필요하다면 담당자나 라벨을 지정합니다.
- 작업 중 공유할 내용이 생기면 Issue 댓글이나 본문에 기록합니다.
- 관련 PR이 있다면 `close #이슈번호` 형식으로 연결합니다.
