# 도심 유휴공간 스마트팜 5축 수치 근거 조사

조사일: 2026-07-15  
대상 작물: 바질, 페퍼민트, 방울토마토, 대파, 루꼴라, 와사비, 상추, 고수
대상 축: 대기온도, 상대습도, 식물광, 미세먼지, 소음

## 결론

현재 근거만으로 8개 작물 모두에 동일한 형식의 ‘정상 범위’를 만드는 것은 불가능하다. 직접 비교시험으로 뒷받침된 후보는 바질의 온도·광, 페퍼민트의 광, 와사비의 유묘 온도·광, 상추의 온도·DLI, 고수의 광에 집중되어 있다. 방울토마토·대파·루꼴라는 이번 조건을 충족하는 독립 축 최적값을 확보하지 못했다.

상대습도는 더 조심해야 한다. 바질의 `RH >= 85%` 등은 노균병 위험 조건이지 생육 최적값이 아니다. 다른 작물의 RH 수치는 대부분 광·양액 시험 중 고정한 실험조건이다. 따라서 바질 병해 위험값만 주장 유형을 분명히 해 검증 파일에 넣었고, 나머지는 격리했다.

사용자가 말한 ‘조도’ 축은 데이터 모델에서 `plant_light`로 바꿨다. lux는 인간 시감도 기반이라 식물 생육 연구의 PPFD·DLI와 직접 비교할 수 없다. Virginia Tech도 식물광 측정에 lux를 권장하지 않고 PPFD와 DLI를 사용하도록 설명한다. lux 채널이 필요하면 사람의 시환경이나 한 광원 내 상대변화용 보조값으로만 수집한다.

미세먼지는 작물 독립 공통축으로 WHO 건강지침과 대한민국 예보·경보 기준을 함께 수록했다. 소음도 작물 독립 공통축으로 대한민국 `Leq dB(A)` 기준표 전체를 넣었지만, 후보지의 용도지역과 도로변 여부가 없으므로 아직 한 행을 선택하지 않았다.

## 파일 구성

- `verified_numeric_evidence.json`: 원문 비교시험 또는 공식 기준으로 수치와 주장 의미를 검증한 레코드다. 범용 정상범위라는 뜻은 아니다.
- `insufficient_evidence.json`: 단순 실험조건, 2차 문헌, 결합처리, 비대상 품종 등 점수 입력으로 쓰기 어려운 값을 격리했다.
- `collection_contract.json`: 하드웨어 선정 전에 고정해야 할 측정량·단위·메타데이터 요구사항이다. 제품이나 샘플링 주기는 정하지 않았다.

기존 `cropinfo/`의 작물별 장문 템플릿은 재사용하지 않았다. 이번 결과는 수치 근거 레코드, 격리 큐, 수집 계약으로 분리한 데이터 중심 구조다.

## 판정 원칙

1. 논문이 말한 값을 그대로 보존한다. ‘시험 내 최고값’을 ‘최적 범위’로 바꾸지 않는다.
2. 대기온도의 일평균, 주·야간 온도, 순간 온도를 섞지 않는다.
3. PPFD, 광주기, DLI, 광질을 분리 저장하고 lux로 환산하지 않는다.
4. RH가 고정조건이면 적정 RH로 채택하지 않는다.
5. PM의 WHO 지침, 대한민국 일평균 예보등급, 2시간 지속 경보는 서로 다른 시간기준으로 저장한다.
6. 소음은 적분시간이 있는 LAeq만 환경기준과 비교한다.
7. 점수 함수, 정상·주의·위험 의미, 가중치, 경보 지속시간은 추후 심층 논의 전까지 만들지 않는다.

## 수집 단계에서 먼저 지킬 사항

- 온도와 RH는 작물 관부 높이의 같은 미기후 지점에서 측정하고 센서 위치를 기록한다.
- 바질 병해 위험을 나중에 다룰 가능성이 있으면 일반 실내 RH 외에 군락 내부 RH와 잎 젖음 수집 여부를 결정해야 한다.
- 식물광 주 채널은 양자센서의 PPFD이며, 하루 누적 DLI를 보존해야 한다. lux만 있는 하드웨어는 이번 작물 수치와 직접 연결할 수 없다.
- PM2.5와 PM10은 둘 다 수집하고, 간이측정기 성능인증 여부·등급·인증번호 및 동시 RH를 저장한다. 2026년 4월 1일 시행 고시가 현재 기준이다.
- 소음은 `dB(A)`라는 숫자 하나가 아니라 `LAeq + 적분시간`과 `Lmax + time weighting`을 보존한다. 후보지 용도지역과 도로변 여부도 데이터다.
- 모든 축에서 원시 시계열을 남긴다. 일평균·24시간 평균·2시간 지속처럼 나중에 필요한 창을 원시값 없이 재구성할 수 없게 만들면 안 된다.

## 다음 논의에서 결정할 것

수치 근거와 별개로 다음 사항은 합의가 필요하다.

- ‘점수’가 생육 최적도, 시설 안전도, 사람 건강, 병해 위험 중 무엇을 뜻하는가
- 시험 내 최고값을 100점으로 둘지, 목표 구간·경고 구간을 별도로 둘지
- 품종·생육단계·주야간·재배방식별 프로필을 몇 개까지 운영할지
- PM에서 WHO 건강지침과 대한민국 예보등급을 UI와 운영 로직에 어떻게 병기할지
- 소음 후보지의 용도지역·도로변 여부와 실제 평가 지점을 어디로 할지
- 센서 정확도, 샘플링 주기, 집계 창, 결측·이상치 처리, 교정 주기
