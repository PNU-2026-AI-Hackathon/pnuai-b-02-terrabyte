# 상추 생육환경 조사

> 형식 버전: `crop-growth-environment-v1`  
> 조사 원칙:
> - 해당 작물 또는 명시된 품종·재배시스템에 직접 적용된 자료만 수치 근거로 사용한다.
> - 실험조건은 최적값으로 검증되지 않았다면 권장값으로 바꾸지 않는다.
> - 직접 확인되지 않은 값은 `직접 근거 없음`으로 기록한다.
> - 서로 다른 측정방식의 토양수분·EC·pH 값은 합치거나 변환하지 않는다.
> - DLI, VPD, 경보 지속시간, 내성 등급을 자료 없이 계산하거나 추정하지 않는다.

### 알림 기준 적용 원칙

- `주의 기준`: 생육 저하 또는 스트레스가 직접 관찰된 수치만 기재한다.
- `위험 기준`: 심각한 장해·병 발생·고사와 직접 연결된 근거가 있을 때만 기재한다.
- `알림 발생까지의 지속시간`: 노출시간이 직접 검증된 경우에만 기재한다.
- `정상 복귀 기준`: 문헌에 회복 또는 경보 해제 기준이 없으면 `직접 근거 없음`으로 둔다.

## 9. 사용자 권장 행동

- 물 주기: 노지에서 주당 1~2 in을 토양·온도에 맞춰 공급하고 수분 변동을 줄인다.
- 관수량 줄이기: 배수가 늦거나 습·건 반복이 심하면 1회량과 빈도를 조정한다.
- 받침대의 고인 물 제거: 화분 받침대의 고인 물을 제거한다.
- 배수구 확인: 배수되는 토양·용기를 유지한다.
- 밝은 위치로 이동: 노지는 전일광을 확보한다. 실내는 품종·시스템별 PPFD를 확인한다.
- 직사광선 피하기: 고온기에 추대·품질 저하가 나타나면 차광과 조기수확을 검토한다.
- 환기하기: 23.9℃ 이상으로 오르거나 결로가 생기면 환기·냉각한다.
- 보온하기: 강한 동결 예상 시 부직포 등으로 보호한다.
- 화분 교체: 최소 화분 깊이·부피 직접 근거 없음. 배수와 재식간격을 확보한다.
- 토양 또는 배지 교체: 배수가 불량하거나 염류가 누적된 배지는 교체한다.
- pH·EC 추가 검사: 수경 EC 1.2~1.8 mS/cm, pH 6.0~7.0 가이드를 시스템에 맞춰 확인한다.
