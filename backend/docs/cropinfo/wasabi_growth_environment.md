# 와사비 생육환경 조사

> 형식 버전: `crop-growth-environment-v1`  
> 조사 원칙:
> - 해당 작물 또는 명시된 품종·재배시스템에 직접 적용된 자료만 수치 근거로 사용한다.
> - 실험조건은 최적값으로 검증되지 않았다면 권장값으로 바꾸지 않는다.
> - 직접 확인되지 않은 값은 `직접 근거 없음`으로 기록한다.
> - 서로 다른 측정방식의 토양수분·EC·pH 값은 합치거나 변환하지 않는다.
> - DLI, VPD, 경보 지속시간, 내성 등급을 자료 없이 계산하거나 추정하지 않는다.

| 시설 재배 적합 여부 | 적합. 온실·식물공장 연구가 있다. |
| 실내 재배 적합 여부 | 가능하지만 광·온도·근권수분 제어가 필요하다. |

### 알림 기준 적용 원칙

- `주의 기준`: 생육 저하 또는 스트레스가 직접 관찰된 수치만 기재한다.
- `위험 기준`: 심각한 장해·병 발생·고사와 직접 연결된 근거가 있을 때만 기재한다.
- `알림 발생까지의 지속시간`: 노출시간이 직접 검증된 경우에만 기재한다.
- `정상 복귀 기준`: 문헌에 회복 또는 경보 해제 기준이 없으면 `직접 근거 없음`으로 둔다.

## 9. 사용자 권장 행동

- 물 주기: 미스트·미세관수로 촉촉함을 유지하되 포화시키지 않는다.
- 관수량 줄이기: 정체수·무름·저산소 징후가 있으면 관수를 줄이고 배수를 회복한다.
- 받침대의 고인 물 제거: 토경 화분에서는 고인 물을 제거한다.
- 배수구 확인: 육묘상과 토경 화분의 자유배수를 확인한다.
- 밝은 위치로 이동: 35 μmol/m²/s 수준의 음지성 신장이 나타나면 조명을 보완한다.
- 직사광선 피하기: 육묘 80%, 성체 50~80% 차광 지침을 참고한다.
- 환기하기: 고온·결로·병해 위험 시 환기하되 VPD가 과도해지지 않게 한다.
- 보온하기: 8℃ 미만에서 생육이 억제되면 보온하고 동결을 피한다.
- 화분 교체: 성체 규격 직접 근거 없음. 깊고 배수성 있으며 수분을 유지할 용기를 선택한다.
- 토양 또는 배지 교체: 느슨하고 부식질이 풍부하며 배수되는 배지로 교체한다.
- pH·EC 추가 검사: pH 6.0~7.0과 반수경 수질, 암모니아성·아질산성 질소를 확인한다.
