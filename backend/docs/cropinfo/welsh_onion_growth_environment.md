# 대파 생육환경 조사

> 형식 버전: `crop-growth-environment-v1`  
> 조사 원칙:
> - 해당 작물 또는 명시된 품종·재배시스템에 직접 적용된 자료만 수치 근거로 사용한다.
> - 실험조건은 최적값으로 검증되지 않았다면 권장값으로 바꾸지 않는다.
> - 직접 확인되지 않은 값은 `직접 근거 없음`으로 기록한다.
> - 서로 다른 측정방식의 토양수분·EC·pH 값은 합치거나 변환하지 않는다.
> - DLI, VPD, 경보 지속시간, 내성 등급을 자료 없이 계산하거나 추정하지 않는다.

### 알림 기준 적용 원칙

- `주의 기준`: 생육 저하 또는 스트레스가 직접 관찰된 수치만 기재한다.
- `위험 기준`: 심각한 장해·병 발생·고사와 직접 연결된 근거가 있을 때만 기재한다.
- `알림 발생까지의 지속시간`: 노출시간이 직접 검증된 경우에만 기재한다.
- `정상 복귀 기준`: 문헌에 회복 또는 경보 해제 기준이 없으면 `직접 근거 없음`으로 둔다.

## 9. 사용자 권장 행동

- 물 주기: 흙이 마르기 전에 뿌리층을 균일하게 적신다.
- 관수량 줄이기: 토양이 지속적으로 젖거나 배수가 늦으면 관수량을 줄인다.
- 받침대의 고인 물 제거: 화분 사용 시 받침대 물을 제거한다.
- 배수구 확인: 배수가 잘되는 토양 조건을 유지한다.
- 밝은 위치로 이동: 저광 증상이 있으면 밝은 위치로 옮긴다.
- 직사광선 피하기: 강광과 함께 잎 노화·품질 저하가 나타나면 차광한다.
- 환기하기: 시설 온도가 적온을 크게 넘거나 결로가 있으면 환기한다.
- 보온하기: 발아·활착기에 7℃ 미만으로 내려가면 보온한다.
- 화분 교체: 화분 규격 직접 근거 없음. 뿌리와 연백부를 수용할 깊이와 배수구를 확보한다.
- 토양 또는 배지 교체: 배수가 불량하거나 다져진 배지는 교체한다.
- pH·EC 추가 검사: 토양 pH 7.0~7.4를 확인하고 EC 측정법을 구분한다.
