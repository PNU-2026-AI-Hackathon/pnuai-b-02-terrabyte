# 페퍼민트 생육환경 조사

> 조사 원칙  
> - 페퍼민트(*Mentha × piperita* L.)를 직접 다룬 자료를 우선 적용한다.  
> - 민트류 일반 자료는 페퍼민트 고유값과 구분한다.  
> - 실험조건은 최적값으로 단정하지 않는다.  
> - 직접 확인되지 않은 값은 `직접 근거 없음`으로 기록한다.  
> - DLI 환산, 내성 등급 판정, 알림 지속시간 설정 등 새로운 추론은 하지 않는다.

---

## 1. 작물 기본정보

- 작물명: 페퍼민트
- 학명: *Mentha × piperita* L.
- 품종:
  - Black Mitcham
  - Todd Mitcham
  - Black Mitcham은 Verticillium 시들음병에 민감하고, Todd Mitcham은 상대적으로 내성이 높은 것으로 소개된다.
- 재배 난이도:
  - 가정재배 기준의 낮음·보통·높음 등급 직접 근거 없음
  - Oregon State University 자료는 상업적 페퍼민트 생산을 적기 관수와 시비가 필요한 까다로운 작물로 설명한다.
- 전체 재배 기간:
  - 다년생
  - 묘목에서 약 90일을 성숙 기준으로 제시한 가정원예 자료가 있다.
  - 잎은 심은 뒤 약 3주부터 수확할 수 있다.
  - 상업 포장은 3~15년 유지될 수 있으며 평균은 5~7년으로 제시된다.
- 주요 생육 단계:
  - 삽목·포복경 활착
  - 유묘
  - 영양생장
  - 꽃봉오리 형성
  - 개화 초기
  - 수확
  - 상업 품종은 불임성 잡종이므로 종자 발아와 결실은 일반적인 생산 단계가 아니다.
- 권장 파종·재배 시기:
  - 종자 파종은 일반적인 상업 번식 방법이 아니다.
  - 삽목묘는 서리 위험이 지난 뒤 옮겨 심는다.
  - 상업용 포복경은 늦가을 또는 봄에 심는 방식이 제시된다.
- 노지·시설·실내 재배 적합 여부:
  - 노지: 적합
  - 시설: 가능
  - 실내: 가능
- 번식 특성:
  - 물민트와 스피어민트의 불임성 잡종
  - 뿌리줄기, 포복경, 삽목으로 번식
- 권장 수확 시기:
  - 잎 이용: 개화 직전
  - 정유 생산: 개화 초기 또는 약 10% 개화 시점

## 3. 광환경

| 조사 항목 | 단위 | 조사 결과 | 비고 |
| --- | --- | --- | --- |
| 일일 권장 일조시간 | 시간 | 최소 3시간/일 | 노지·화분 재배 자료에서 제시한 최소 직사광 시간이며 최적 일조시간은 아니다. |
| 권장 광주기 | 시간/일 | 최적값 직접 근거 없음 | 실내 시험에서 14시간, 다른 LED 시험에서 16시간을 사용했다. 모두 실험조건이다. |
| 적정 PPFD | μmol/m²/s | 150 | 2025년 실내 화분시험에서 페퍼민트 생장이 가장 좋았던 처리 |
| 적정 DLI | mol/m²/day | 직접 근거 없음 | PPFD와 광주기로 새로 계산하지 않음 |
| 강한 직사광선 내성 | 낮음·보통·높음 | 등급 직접 근거 없음 | 양지부터 반그늘까지 재배 가능. 실내 LED 200 μmol/m²/s 초과 시 잎 황화가 관찰됐으나 자연 직사광선 시험은 아니다. |
| 저광 환경 내성 | 낮음·보통·높음 | 등급 직접 근거 없음 | 반그늘 재배 가능. 20 μmol/m²/s 처리에서는 광 부족성 줄기 신장이 나타났다. |
| 생육 단계별 광 요구량 차이 | 설명 | 직접 비교자료 없음 | 발아·활착·영양생장·개화 단계를 같은 설계로 비교한 연구 미확인 |

### 실내 광환경 연구 조건

- PPFD 처리: 20, 50, 100, 150, 200, 250 μmol/m²/s
- 페퍼민트 생장이 가장 좋았던 처리: `150 μmol/m²/s`
- 20 μmol/m²/s: 광 부족성 줄기 신장 관찰
- 200 μmol/m²/s 초과: 잎 황화 관찰
- 250 μmol/m²/s: 광저해와 황화 보고
- 광주기: 14시간
- 온도: 20~27℃
- 상대습도: 30~60%
- 화분 부피: 0.9 L
- 위 조건은 특정 실내시험 결과이며 노지 자연광에 직접 적용할 수 없다.

### 민트속 전체 참고값

- `150~200 μmol/m²/s`
- 해당 연구에서 Mentha 종 전체에 적합하다고 평가한 범위
- 페퍼민트 단독 최적 범위로 단정하지 않는다.

## 4. 토양·배지 환경

| 조사 항목 | 기록 내용 |
| --- | --- |
| 선호 토성 | 특정 토성 분류의 직접 근거 없음. 깊고, 부식질이 풍부하며, 느슨하고, 배수가 잘되면서 수분 보유력이 있는 토양을 선호한다. |
| 허용 가능한 토성 | 충분히 배수된다면 비교적 다양한 토양에서 자랄 수 있다. 습한 중점토도 배수가 확보되면 재배 가능하다고 제시된다. |
| 배수성 요구도 | 등급 직접 근거 없음. 충분한 배수가 필요하며 겨울철 침수 상태에서는 생육이 나빠지거나 고사할 수 있다. |
| 보수성 요구도 | 등급 직접 근거 없음. 좋은 수분 보유력과 지속적인 수분 공급이 요구된다. |
| 통기성 요구도 | 등급 직접 근거 없음. 얕은 뿌리가 침투할 수 있도록 느슨한 토양 질감이 요구된다. |
| 과습 내성 | 등급 직접 근거 없음. 지속적인 침수·질척한 토양은 부적합하다. |
| 건조 내성 | 등급 직접 근거 없음. 풍부한 수분과 관수가 필요한 얕은 뿌리 작물로 설명된다. |
| 토양 다짐 민감도 | 등급 직접 근거 없음. 뿌리 침투를 위해 느슨한 토양이 필요하다. |
| 적정 토양 pH | 자료별 차이 있음: NC State 6.0~7.0, Purdue 상업재배 5.5~6.5, 생산지침 5.5~7.0 |
| 허용 pH | 적정 범위와 구분된 별도 허용 한계 직접 근거 없음 |
| 적정 EC | 수경 양액 1.4 dS/m |
| 염류 내성 | 등급 직접 근거 없음. 수경시험에서 10 또는 20 mM NaCl 처리가 생체중과 초장에 뚜렷한 감소를 일으키지 않았으나 일반 토양의 내성 등급으로 환산할 수 없다. |
| 유기물 요구도 | 등급 직접 근거 없음. 부식질과 유기물이 풍부한 토양이 권장된다. |
| 비옥도 요구도 | 상업 생산자료에서 상대적으로 높은 비옥도가 필요하다고 설명한다. |
| 최소 유효 토심 | 보편적 최소값 직접 근거 없음. OSU 노지 관개 계산 예시는 유효 근권 깊이 24 in을 사용한다. |
| 권장 화분 깊이 | 최소 6 in |
| 권장 화분 부피 | 5 gal 버킷이 적절한 용기 예로 제시됨. L로 환산하지 않음 |
| 권장 화분 폭 | 12~16 in |
| 배수구 필요 조건 | 화분 바닥에 배수구가 필요하며 배수구가 막히지 않도록 관리한다. |
| 권장 배지 구성 | 정해진 혼합비 직접 근거 없음. 배수가 되는 양질의 화분용 상토가 권장된다. |

| 관수 후 권장 상태 | 설명 | 흙 전체가 균일하게 촉촉하되 물에 잠기거나 질척하지 않은 상태 | 실내 화분 자료는 배지를 고르게 촉촉하게 유지하도록 안내한다. |
| 물이 고였을 때 위험해지는 시간 | 시간 | 직접 근거 없음 | 몇 시간 후 피해가 시작되는지 검증한 자료 미확인 |

### 참고한 근권 수온

- 수경 염류시험에서 관찰된 양액 온도: `18.4~28.1℃`
- 적정 수온으로 검증된 값이 아니라 해당 시험에서 관찰된 범위다.

### 토양수분 측정 기준

OSU 자료의 `35%`는 토양센서가 표시하는 “35% 수분”이 아니다.

- 포장용수량에서 식물이 이용할 수 있는 물의 35%가 소비된 상태를 뜻한다.
- 유효 근권 깊이, 토양의 수분저장량, 증발산량을 이용한 노지 관개 계산이다.
- 일반 화분 센서의 0~100 상대값이나 체적수분함량(VWC)에 그대로 입력할 수 없다.

## 6. 생육 단계별 환경

필요한 단계만 작성한다.

```text
삽목·포복경 활착
유묘
영양생장
개화
수확
```

| 생육 단계 | 온도 | 습도 | 토양수분 | 토양온도 | 광량 | 주요 주의사항 |
| --- | --- | --- | --- | --- | --- | --- |
| 발아 | 해당 없음 | 해당 없음 | 해당 없음 | 해당 없음 | 해당 없음 | 상업 품종은 불임성 잡종이므로 종자 발아를 표준 번식 단계로 적용하지 않는다. |

## 9. 사용자 권장 행동

- 물 주기
  - 흙 전체가 다시 고르게 촉촉해지도록 관수한다.
  - 노지에서는 이용 가능 수분의 35% 소모 기준을 참고할 수 있다.
- 관수량 줄이기
  - 배지가 계속 질척하거나 배수구에서 물이 빠지지 않을 때 관수 빈도와 양을 줄인다.
- 받침대의 고인 물 제거
  - 관수 뒤 받침대에 남은 물을 제거한다.
- 배수구 확인
  - 화분 바닥 배수구가 흙이나 뿌리로 막히지 않았는지 확인한다.
- 밝은 위치로 이동
  - 하루 최소 3시간의 햇빛을 확보한다.
  - 실내 저광에서는 재배등을 사용할 수 있다.
- 직사광선 피하기
  - 자연 직사광선 위험 기준 직접 근거 없음
  - 실내 LED 아래에서 잎 황화가 나타나고 PPFD가 200 μmol/m²/s를 넘는 경우 조명 출력을 낮추거나 거리를 늘린다.
- 환기하기
  - 실내가 덥거나 잎과 배지가 장시간 축축한 경우 공기 흐름을 확보한다.
  - 환기 개시 온습도 수치는 직접 근거 없음
- 보온하기
  - 서리 위험이 있을 때 화분을 실내로 옮기거나 보온한다.
  - 저온 경보 온도는 직접 근거 없음
- 화분 교체
  - 최소 깊이 6 in, 폭 12~16 in 또는 배수구가 있는 5 gal급 용기 자료를 참고한다.
- 토양 또는 배지 교체
  - 토양이 지속적으로 질척하거나 다져졌다면 배수가 되는 양질의 화분용 상토로 교체한다.
- pH·EC 추가 검사
  - 토양 pH를 검사한다.
  - 자료별 적정 pH는 5.5~6.5, 6.0~7.0, 5.5~7.0으로 차이가 있다.
  - 수경재배에서는 해당 연구와 같은 시스템일 때 EC 1.4 dS/m를 참고할 수 있다.
  - 토양재배 EC에 그대로 적용하지 않는다.
