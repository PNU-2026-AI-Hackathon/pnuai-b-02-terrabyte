# 루꼴라 생육환경 조사

> 형식 버전: `crop-growth-environment-v1`  
> 조사 원칙:
> - 해당 작물 또는 명시된 품종·재배시스템에 직접 적용된 자료만 수치 근거로 사용한다.
> - 실험조건은 최적값으로 검증되지 않았다면 권장값으로 바꾸지 않는다.
> - 직접 확인되지 않은 값은 `직접 근거 없음`으로 기록한다.
> - 서로 다른 측정방식의 토양수분·EC·pH 값은 합치거나 변환하지 않는다.
> - DLI, VPD, 경보 지속시간, 내성 등급을 자료 없이 계산하거나 추정하지 않는다.

### 알림 기준 적용 원칙

- `주의 기준`: 생육 저하 또는 스트레스가 직접 관찰된 수치만 기재한다.
- `위험 기준`: 심각한 장해·병 발생·고사와 직접 연결된 근거가 있을 때만 기재한다.
- `알림 발생까지의 지속시간`: 노출시간이 직접 검증된 경우에만 기재한다.
- `정상 복귀 기준`: 문헌에 회복 또는 경보 해제 기준이 없으면 `직접 근거 없음`으로 둔다.

## 9. 사용자 권장 행동

- 물 주기: 표토 약 1 in이 말랐을 때 깊고 고르게 관수하거나 동일 자동관수 배지에서는 VWC 0.30을 유지한다.
- 관수량 줄이기: 배수가 늦고 근권이 포화되면 관수량을 줄인다.
- 받침대의 고인 물 제거: 화분 받침대 물을 제거한다.
- 배수구 확인: 과도한 관수를 피하고 배수구를 확보한다.
- 밝은 위치로 이동: 4~6시간의 반일광~전일광을 확보한다.
- 직사광선 피하기: 고온기에 일소·추대가 나타나면 차광한다.
- 환기하기: 시설 과열과 결로를 줄인다.
- 보온하기: 발아 저온으로 출아가 지연되면 온도를 조절한다.
- 화분 교체: 권장 화분 깊이·부피 직접 근거 없음. 배수구와 재식면적을 확보한다.
- 토양 또는 배지 교체: 센서 사용 시 배지별 보정곡선이 없으면 재보정한다.
- pH·EC 추가 검사: NFT에서는 EC 1.5~1.8 dS/m를 품종·시스템 한정값으로 확인한다.
